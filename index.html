Power BI Relational Star Schema
1 Fact Table joined with 5 Dimension Tables
⭐ Fact_Transactions (5,000 Records)
transaction_id [PK], customer_id [FK], gateway_id [FK], method_id [FK], amount, status, processing_seconds, is_recovered, recovered_amount
🔹 Dim_Gateway (3 Gateways)
gateway_name (Razorpay, Cashfree, PayU), SLA Target (3s), Payout Cycle (T+2), Fee % (2.0%)
🔹 Dim_PaymentMethod (5 Methods)
payment_method (GPay, Credit Card, Debit Card, NetBanking, Wallet), Channel Type (Fast/Instant vs Batch)
🔹 Dim_Date & Dim_Customer
Date Hierarchy (Month, Week, Day, Hour, Peak Window) & Customer Profile (Rolling historical failure rate)
Production DAX Measures Library
Used across headline KPIs & drill-through matrices
[Failure Rate %] =
DIVIDE(CALCULATE(COUNTROWS(Fact_Transactions), Fact_Transactions[status] = "FAILED"), COUNTROWS(Fact_Transactions), 0)
[Retry Recovery Volume] =
CALCULATE(SUM(Fact_Transactions[recovered_amount]), Fact_Transactions[is_recovered] = 1)
[Pending SLA Breach] =
CALCULATE(COUNTROWS(Fact_Transactions), Fact_Transactions[status] = "PENDING" && Fact_Transactions[processing_seconds] > 900)
[Net Settlement Gap] =
SUM(vw_settlement_gap[gap_amount])
